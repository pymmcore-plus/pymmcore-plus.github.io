# pymmcore\_widgets.hcwizard

Configuration wizard creating/editing a MicroManager configuration file.

**Submodules**

| Name | Description |
| --- | --- |
| `delay_page` | Config wizard, step 4: set delays for devices that can't report when they're done. |
| `devices_page` | Config wizard, step 2: add and remove devices. |
| `finish_page` | Config wizard, last step: save the configuration file. |
| `intro_page` | Config wizard, step 1: start a new configuration or edit an existing file. |
| `labels_page` | Config wizard, step 5: name the positions of state devices (filter wheels...). |
| `roles_page` | Config wizard, step 3: choose default devices and the auto-shutter setting. |

## Re-exports

These can also be imported from this module, but each is documented under its shortest import path (linked below).
