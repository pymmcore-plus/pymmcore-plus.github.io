# pymmcore\_plus.metadata.schema

## Re-exports

These names can be imported from this module, but are documented at their top-level location.

| Name | Description |
| --- | --- |
| `ConfigGroup` | A group of configuration presets. |
| `ConfigPreset` | A group of device property settings. |
| `DeviceInfo` | Information about a specific device. |
| `FrameMetaV1` | Metadata for a single frame. |
| `ImageInfo` | Information about the image format for a camera device. |
| `PixelSizeConfigPreset` | A specialized group of device property settings for a pixel size preset. |
| `Position` | Represents a position in 3D space and focus. |
| `PropertyInfo` | Information about a single device property. |
| `PropertyValue` | A single device property setting. |
| `SummaryMetaV1` | Complete summary metadata for the system. |
| `SystemInfo` | General system information. |
