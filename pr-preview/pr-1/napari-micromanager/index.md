# napari-micromanager

`napari-micromanager` is a [napari](<https://napari.org>) plugin that turns napari into a microscope control application, powered by [pymmcore-plus](<https://pymmcore-plus.github.io/pymmcore-plus/index.md>) and [pymmcore-widgets](<https://pymmcore-plus.github.io/pymmcore-widgets/index.md>). Images you snap or acquire show up as napari layers, right next to whatever analysis you do in napari.

> [!NOTE]
>
> **Development has moved to pymmcore-gui**
>
> `napari-micromanager` continues to be maintained, but current development is focused on [pymmcore-gui](<https://pymmcore-plus.github.io/pymmcore-gui/index.md>), a napari-independent application (using [ndv](<https://github.com/pyapp-kit/ndv>) for viewing), for reasons of performance and fewer dependencies. If you don't need napari, start with pymmcore-gui.

- [Installing and launching](<https://pymmcore-plus.github.io/napari-micromanager/getting_started/index.md>) the plugin.
- [Scripting](<https://pymmcore-plus.github.io/napari-micromanager/scripting/index.md>): drive napari-micromanager from Python.
